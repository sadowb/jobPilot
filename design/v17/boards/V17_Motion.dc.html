V17 · Motion spec · every animation in the product

Things move only to explain.

Demo tiles loop so you can watch each one. The durations on each card are the product values. Cap is the only thing with personality: everything else is a fast, plain transition.

Shared easing and rulesevery motion obeys these
OUT
cubic-bezier(.2,.8,.2,1). Things arrive and settle.
IN-OUT
cubic-bezier(.65,0,.35,1). Cap flights, loops and leaving rows.
SPRING
cubic-bezier(.34,1.56,.64,1). Pops and the one celebration.
REDUCED
prefers-reduced-motion: every animation is set to none. The end state is the design, so nothing is lost.
