# jobPilot

Desktop app (Electron + Vite + React + TypeScript + Tailwind v4) for JobPilot, an agent that fills job applications and lets you watch or take over.

Status: **design source imported; app not scaffolded yet.**

- Design spec (read first): [docs/FRONTEND.md](docs/FRONTEND.md)
- Design source of truth: `design/v17/` (67 artboards exported from the Claude Design canvas, page "V 17 · Full flow")
- Tokens: `design/tokens.json` · Brand SVGs: `design/brand/`

The UI must match the V17 boards one to one, light and dark.
